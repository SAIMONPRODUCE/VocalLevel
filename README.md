# VocalLevel 🎙️

Normalizador dinámico e inteligente de voz para YouTube.

## ✨ Características
- **Detección inteligente de partes bajas:** Analiza el audio y eleva únicamente los tramos donde el nivel de voz cae.
- **Sin artefactos ni bombeos:** Ajuste suave de ganancia sin amplificar silencios o ruidos de fondo.
- **Limitador de seguridad (-1 dB):** Evita saturaciones o picos molestos.
- **Guardado directo:** Coloca los archivos listos directamente en tu carpeta de trabajo.
- **Interfaz moderna:** Estilo Apple / Modo Oscuro con soporte de arrastrar y soltar.

## 🚀 Uso Rápido
Haz doble clic sobre `Iniciar VocalLevel.command` para abrir la app automáticamente.
O ejecuta por terminal:
```bash
python3 app.py
```
